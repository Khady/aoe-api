## Source handling notes

- The supplied launcher is a concrete working-client reference, not publisher documentation. Its short URL-lifetime and deletion comments are attributed rather than treated as guarantees.
- LibreMatch provides firsthand community protocol research. Some endpoint examples are AoE2-specific; AoE4 applicability is marked separately.
- Its full-repository follow-up has a [coverage guide](librematch.md), [172-page index](../catalog/librematch-coverage.json), and separate [source-fetch metadata](../evidence/2026-09-19/librematch-review.json). The linked OpenAPI and protobuf declarations were inspected without installing clients or exercising game-session operations.
- AoECenter source is indexed in a [request/model coverage map](../catalog/aoecenter-coverage.json), with [fetch hashes and an offline fixture check](../evidence/2026-09-19/aoecenter-review.json). Fixtures were examined without copying captured player data into this workspace or executing the SDK/authentication tools.
- ageLANServer’s [route/event/resource index](../catalog/agelanserver-coverage.json) and [review evidence](../evidence/2026-09-19/agelanserver-review.json) pin its emulator implementation. Static, unavailable and local-only handlers are distinguished from live publisher services; no launcher, server, relay or login flow was run.
- The official JavaScript bundle declares both read and state-changing operations. Declared paths without verified methods have `method:null` in the catalog.
- AoE4 Guides live OpenAPI is included as a dated provider snapshot with its original title/contact/license metadata. The deployed spec is not assumed identical to the inspected GitHub branch.
- The old LibreMatch wiki hostname failed TLS verification; the project’s GitHub source and GitHub Pages documentation were used instead.
- Some source pages were discoverable through web search but blocked direct fetches. This is recorded as an access limitation, not inferred service retirement.
- Local SCAR reference hashes and paths are in [local metadata](../evidence/2026-09-19/local-scar-metadata.json); their contents were read without changing the installation.
